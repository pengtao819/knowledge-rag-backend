## 一、项目定位

**做一个基于 FastAPI + LangChain + LangGraph 的知识库智能问答后端系统**  
这个项目能覆盖你目前的技术栈，并且直接对标 AI 应用开发 / 大模型后端实习岗位。

核心功能：  

- 上传 PDF 文档，系统解析并向量化存储  
- 用户提问时，通过 RAG（检索增强生成）从知识库检索相关内容，调用大模型生成回答  
- 集成一个简易 Agent，能自动判断是否需要调用工具（如搜索知识库、查询文档列表）  
- 用 MySQL 持久化对话记录，支持多轮对话  
- 封装异步 LLM 调用，增加超时、异常处理和重试机制  
- 设计防幻觉机制，提高回答可信度

---

## 二、项目需要实现的功能模块

| 模块               | 具体内容                                                     |
| ------------------ | ------------------------------------------------------------ |
| **文档上传与解析** | 接收 PDF 文件，提取文本，进行分块（chunk）                   |
| **向量化与存储**   | 将文本块转为向量，存入向量数据库（推荐 Chroma）              |
| **RAG 问答**       | 用户提问 → 检索 top-k 相关片段 → 拼接 Prompt → 调用 LLM 生成回答，并附引用来源 |
| **Agent 工具调用** | 使用 LangGraph 定义流程，根据用户问题自动调用工具（如检索知识库、获取文档列表） |
| **异步 LLM 封装**  | 使用异步客户端调用大模型，设置超时（如10秒），捕获异常，失败自动重试 |
| **对话持久化**     | 用 SQLAlchemy 异步操作 MySQL，保存每轮对话和元数据，支持历史查询 |
| **防幻觉机制**     | 在 Prompt 中限制回答范围，要求引用来源；可加后处理检测回答与上下文一致性 |
| **API 接口**       | `/upload` 上传文档；`/chat` 对话（支持流式输出）；`/history` 查询历史记录 |

## 三、技术栈清单

- **后端框架**：FastAPI（异步）
- **AI 框架**：LangChain（文档加载、分割、检索链）、LangGraph（Agent 状态图）
- **大模型**：OpenAI API 或兼容接口（也可用开源模型，如 ChatGLM、Qwen）
- **向量数据库**：Chroma（轻量、易持久化）
- **数据库**：MySQL（异步驱动 aiomysql + SQLAlchemy）
- **其他库**：PyPDF2 / pdfplumber（PDF解析）、sentence-transformers（本地向量化，可选）、tenacity（重试）
- **部署**：Docker（可选）、云服务器或 Render/Railway 免费部署

## 六、面试准备要点（可能被问到）

1. **为什么用 LangGraph？**  
   答：相比 LangChain 的简单 Chain，LangGraph 更适合有状态、多步骤、条件分支的 Agent 流程，可以灵活定义节点和边。

2. **如何解决大模型幻觉？**  
   答：通过 RAG 提供可信上下文；Prompt 中限制回答范围；要求引用来源；后处理检测回答与上下文一致性。

3. **异步 LLM 调用怎么实现？超时了怎么办？**  
   答：使用 AsyncOpenAI 客户端，设置 timeout，捕获超时异常，返回友好错误，并用 tenacity 做有限重试。

4. **为什么选 Chroma？**  
   答：轻量、易嵌入、支持持久化，适合小型项目；大规模场景可替换为 Milvus 等。

5. **如何处理多轮对话？**  
   答：从数据库读取最近 N 轮消息拼接上下文，或使用 LangChain 记忆模块，注意 token 消耗。

6. **上传大 PDF 怎么办？**  
   答：分块处理，用后台任务队列（如 Celery）异步解析，避免阻塞请求。

7. **向量检索的原理？**  
   答：将文本转为向量，用余弦相似度或内积计算查询向量与文档向量的相似度，返回 top-k。

# 开发顺序

1. 创建上面全部文件夹、空文件
2. 填写 `.env`、`config.py`，读取环境变量
3. `app/db/database.py`：编写异步 MySQL 连接，定义两张表（文档表、对话历史表），测试数据库连通
4. `app/services/llm_client.py`：封装异步大模型调用，测试超时、重试、JSON 结构化输出
5. `app/services/rag_service.py`：写 RAG 逻辑，**先独立脚本跑通，不要直接对接接口**
6. `app/api/rag_api.py`：编写上传、问答接口，对接 FastAPI，测试 PDF 上传问答
7. 对接 MySQL，把文档元信息、对话记录存入数据库
8. `app/services/agent_service.py`：实现 LangGraph 简易 Agent 与工具
9. `app/api/agent_api.py` 封装 Agent 接口
10. main.py 注册全部路由，全局异常捕获
11. 补全 README.md，推送到 GitHub

> 提示：`.env` 文件存放密钥密码，**上传 GitHub 一定要忽略这个文件，不要泄露密钥**
